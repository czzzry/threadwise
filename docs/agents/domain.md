# Domain Docs

This is a single-context repository. `CONTEXT.md` owns the current stage, document read order, trust order, and historical/current boundary.

## Before exploring

1. Read `AGENTS.md` for stable workflow and safety rules.
2. Read `CONTEXT.md` for the current product and document state.
3. Read the current task-specific PRD or triaged issue identified by the user or `CONTEXT.md`.
4. Read ADRs under `docs/adr/` that govern the modules or product decisions being examined.

Treat candidate issue maps, archives, old handoffs, and completed-slice documents as historical unless the current task or `CONTEXT.md` explicitly activates them.

## Vocabulary and decisions

Use domain terms from `CONTEXT.md`. If a proposal conflicts with an ADR, surface the conflict instead of silently overriding it.
